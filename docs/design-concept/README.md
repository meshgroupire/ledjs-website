# LEDJS growth concept

Open `index.html` directly in a browser. Its photographs reference the existing `public/images` directory, so retain this folder inside the repository.

The revised concept leads with wedding DJs. `wedding-dj.html` and `songo-music-bingo.html` preview the researched service copy. The Songo wordmark is a temporary official reference until the owner's approved franchise asset pack is available. The rejected legacy photograph is no longer in public assets. Ticket wireframes are hidden in the local concept and are not part of the current production app.

This is a local design proposal, not a deployed website. The enquiry confirmation is simulated, ticket checkout never takes payment, and sample events and prices are clearly labelled. The WhatsApp link uses the Irish international form of the number currently displayed in the footer; verify ownership and WhatsApp availability before launch.

Open `review.html` for the source audit, recommended architecture, search strategy, delivery phases and acceptance criteria. The editable source is `proposed-review.md`. `design-direction.md` records the UI skill's design plan and critique.

`desktop-preview.png` and `mobile-preview.png` show the concept. Browser verification is recorded in `verification.md`; rerun the helper from the repository root with `node docs/design-concept/verify-concept.cjs` (Node 22+ and installed Chrome, or set `CONCEPT_CHROME` to the browser executable).
